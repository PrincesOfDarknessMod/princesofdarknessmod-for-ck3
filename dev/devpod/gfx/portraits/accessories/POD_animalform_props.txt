#
# node = body_root parents the whole creature to the character's body root,
# which is how PoD does full-creature replacement (POD_props.txt: pod_horse_idle,

# the mesh rigged to the character's own skeleton; each of these models carries
# its own rig, so node = is the only option.
#
# This file only supplies geometry. Hiding the human is the portrait modifier's
# job (gene_bs_body_type -> no_portrait).
######################################################################
