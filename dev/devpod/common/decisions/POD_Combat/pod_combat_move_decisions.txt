# One hidden decision per combat move. The
# is_valid_showing_failures_only block stores the unlock
# requirements (trait/faith/perk). The trigger
# POD_can_execute_combat_move reads the stored decision via
# can_execute_decision to validate access without the
# decisions ever appearing in the player's decisions panel —
# window_decisions.gui hides decision_group_type = hidden.
#
# Decisions omit explicit desc = <X>. CK3 auto-resolves
# <decision_id>_desc; the matching loc key points that at
# PODCombatMoveDesc which renders the rich inline card.
