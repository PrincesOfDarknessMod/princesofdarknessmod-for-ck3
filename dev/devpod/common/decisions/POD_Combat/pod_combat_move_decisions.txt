######################################################
######   POD COMBAT MOVE DECISIONS
######################################################
# One hidden decision per combat move, supplying the move's
# illustration and its failure-description material: the
# is_valid_showing_failures_only block calls the move's shared
# character-scoped unlock trigger, allowing the loadout editor
# to render unmet requirements without a second predicate body.
# Runtime story lookups use pod_combat_actor_unlocks_move_trigger
# as an adapter to that same per-move rule; can_execute_decision
# is not used because implicit decision-taker requirements reject
# generic unlanded combatants. Hidden decisions never appear in
# the player decisions panel -
# window_decisions.gui hides decision_group_type = hidden.
#
# Decisions omit explicit desc = <X>. CK3 auto-resolves
# <decision_id>_desc; the matching loc key points that at
# PODCombatMoveDesc which renders the rich inline card.
