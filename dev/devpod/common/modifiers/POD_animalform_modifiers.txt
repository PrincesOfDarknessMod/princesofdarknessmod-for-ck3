######################################################################
# Marker modifiers for the naturalistic animal portrait forms.
#
# Pure state markers with no numeric effects, read only by the
# POD_animalform_*_trigger family. Character modifiers rather than flags because
# adding or removing one reliably refreshes the portrait, which is how PoD's own
# forms drive their model swaps; a flag change can leave the old model on screen
# until the character view is reopened.
#
# The triggers also accept POD_animalform_<x>_flag, so other content can drive a
# form without adding a modifier.
######################################################################
