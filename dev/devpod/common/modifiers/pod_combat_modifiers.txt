######################################################
###### POD COMBAT - MARKER MODIFIERS
######################################################
# Combat-owned character modifiers. Deliberately NOT added to PoD's
# own 00_POD_misc_modifiers.txt: a new file is not a delta, so a PoD
# re-sync cannot silently drop it and it needs no verify_deltas.py row.
# CK3 loads every file under common/modifiers regardless of name.
#
# A marker modifier is applied to a move's user by the move's
# marker_modifier setter (POD_execute_combat_move section 12c) and read
# back by the has_modifier condition predicate, which lets one move gate
# or bonus off the state another move left behind.
#
# Adding a marker key means, in lockstep:
#   - a block here, plus its name / _desc keys in POD_combat_static_l_english.yml
#   - a MARKER_MODIFIERS entry in generate_combat_files.py
#   - a case in the section 12c apply switch (pod_combat_move_effects.txt)
#   - a case in the 12b-marker strip switch (pod_combat_strip_marker_effect,
#     pod_combat_move_effects.txt)
#   - a removal line in pod_combat_duel_end_effect, pod_combat_host_died_release_effect
#     and the slot-init self-heal (pod_combat_init_slot_from_character_effect)
######################################################
