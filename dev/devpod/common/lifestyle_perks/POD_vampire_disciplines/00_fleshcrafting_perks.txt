# Not a normal lifestyle. Perks are "hidden" and are only assigned with the Fleshcrafting GUI

# When adding new perks, remember to also add them in the other places where they're listed:
# - The effect injectors in common\scripted_effects\POD_injectors\POD_injectors_lifestyle_perks.txt
# - The trigger injectors in common\scripted_triggers\POD_injectors\POD_trigger_injectors_perks.txt
# - The script values in common\script_values\POD_fleshcrafting_values.txt
# The injectors are categorized by body part and layer, e.g. POD_perk_injector_fc_head_flesh (or POD_perk_injector_trigger_fc_head_flesh for the trigger)
# Each perk needs a complexity script_value that ends in _complexity, e.g. fc_head_bat_ears_perk_complexity
